# titrit cake

موقع ثابت (HTML/CSS/JS) لعلامة **titrit cake**: كيك مخصّص في الرباط وسلا.

## الملفات
- `index.html`: بنية الصفحة والنصوص
- `style.css`: الألوان والتصميم
- `script.js`: المعرض ونموذج الطلب. رقم واتساب وحساب إنستغرام في أعلاه
- `images/`: صور الكيك والشعار

## النشر على GitHub Pages
1. أنشئي مستودعاً جديداً على GitHub وارفعي كل الملفات إلى الفرع `main` (مع مجلد `images`).
2. من **Settings ثم Pages**: اختاري Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)`، ثم Save.
3. بعد دقائق يظهر الموقع على `https://اسم-المستخدم.github.io/اسم-المستودع/`.

## التعديل
- **إضافة كيكة:** ضعي الصورة في `images/` وأضيفي سطراً جديداً في `D` داخل `script.js` (الاسم `n` والقسم `c` والمسار `s`).
- **تغيير الرقم:** عدّلي `PHONE` في `script.js`، وابحثي عن `212617598717` في `index.html`.
- **الروابط:** إنستغرام `titritcake`، وفيسبوك في تذييل `index.html`.
